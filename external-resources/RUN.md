# RUN · 润：中国护照持有人的海外移居手册

- **项目地址：** https://github.com/BryceYuuu/RUN
- **项目类型：** 海外移居与签证路线资料库
- **简介：** 面向中国护照持有人的海外移居手册，整理欧洲 36 国的 110 条移民路线及 13 个主要移民地区，覆盖数字游民签证、欧盟蓝卡、技术移民、留学转工作、创业自雇、投资居留等方向，并为路线提供官方来源。
- **语言/技术：** Python
